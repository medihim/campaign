# IPPEO Campaign Learning Playbook v2.4

메디힘 × 이뻐(IPPEO) 내부 공유용 캠페인 운영 프레임워크입니다.

## 구성

- `index.html` : GitHub Pages용 메인 문서
- `.nojekyll` : GitHub Pages에서 정적 파일을 그대로 제공하기 위한 설정
- `DEPLOY_GITHUB_PAGES.md` : GitHub Pages 배포 방법
- `VERSION.md` : 현재 버전과 주요 반영사항

## 주요 문서 범위

1. 기존/신규 랜딩 구조
2. 일본 타깃 고객 의사결정 벡터
3. 퍼널 및 필수 Tracking Event
4. 랜딩 × 벡터 × 퍼널 연결
5. 10월 10일 이후 캠페인 시나리오
6. 필요 과업 / 담당 / 작업시간 / 산출물 / 리드타임
7. 병원 브랜드 벡터 및 스코어 기반 병원 유형
8. 캠페인 버저닝 체계

## 비밀번호 보호

현재 문서는 브라우저에서 동작하는 클라이언트 측 비밀번호 게이트가 적용되어 있습니다.

> 중요: 이는 내부 공유 편의용 접근 제한입니다.  
> HTML 소스에 로직이 포함되므로, 기밀자료를 보호하는 서버 인증 수준의 보안은 아닙니다.

## 폰트

Pretendard 웹폰트를 우선 사용하며, 네트워크 환경에서 웹폰트 로딩이 되지 않을 경우 시스템 한글 폰트로 자동 대체됩니다.
